# Prakash - Cinematic Portfolio

A high-performance modern developer portfolio featuring an interactive, full-page transparent scroll animation, responsive layouts for both mobile and desktop screens, and sleek glassmorphic UI.

## Features

- **Seamless Transparent Scroll Animation:** 240 high-resolution WebP frames dynamically rendered on HTML5 canvas with zero red fringe and smooth inertia interpolation (LERP).
- **Responsive Design:** Adaptive experience across mobile devices (with full-screen mobile menu drawer) and desktop browsers.
- **Fast & Lightweight:** Two-phase progressive loading with immediate interactivity and keyframe caching.
- **Vercel Optimized:** Configured for Vercel edge caching and static performance.

## Tech Stack

- **Frontend:** Vanilla HTML5, CSS3, Modern JavaScript (ES6+)
- **Canvas Engine:** Dual-buffer HTML5 2D Canvas with sub-pixel interpolation
- **Hosting:** Vercel

## Local Development

```bash
# Start local server
npm start
# Open http://localhost:3000 in your browser
```
